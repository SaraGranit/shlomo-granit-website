# אתר הרב שלמה גרנית

אתר תדמית בעברית ובכיווניות מימין לשמאל, הכולל עמוד בית וארבעה תחומי פעילות: שיעורים והרצאות, עריכת חופות, ייעוץ וגישור, שלום בית וחינוך.

## הרצה

נדרשת סביבת Node.js תואמת ל־Vite. הפרויקט נבדק עם Node.js 22.14.

```powershell
npm --prefix website ci
npm --prefix website run dev
```

הכתובת המקומית תוצג במסוף, בדרך כלל http://localhost:5173/ .

## מבנה הפרויקט

- [website/README.md](website/README.md): הוראות בנייה ובדיקות, ניהול תוכן ומידע לפני פרסום.
- [SITE_PLAN.md](SITE_PLAN.md): האפיון הראשוני.
- [DESIGN.md](DESIGN.md): הצעת העיצוב ורישום האישור למימוש.
- [design/home.svg](design/home.svg) ו־[design/weddings.svg](design/weddings.svg): הדמיות העיצוב המקוריות.

## מצב האתר

האתר מיועד בשלב זה לפיתוח ולבדיקה, לא לפרסום סופי. מספרי הקשר טרם נמסרו, התצלום הוא להמחשה בלבד, והרקע התורני דורש אישור לפרסום. האתר אינו כולל איסוף פניות או שירות מעקב. העלאת הקוד למאגר אינה פריסה של האתר לאינטרנט.
