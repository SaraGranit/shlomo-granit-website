# אתר הרב שלמה גרנית

אתר בעברית ובכיווניות מימין לשמאל. כולל עמוד בית, ארבעה עמודי פעילות, מידע על פרטיות ונגישות ועמוד לכתובת שאינה קיימת.

## הרצה מקומית

מתוך תיקיית העבודה הראשית:

```powershell
npm --prefix website run dev
```

הכתובת הרגילה היא http://localhost:5173/ . אם הפורט תפוס, כתובת השרת תופיע במסוף.

## בדיקות

```powershell
npm --prefix website run build
Push-Location website
npx playwright test tests/site.spec.ts --workers=1 --reporter=list
Pop-Location
```

בדיקות הדפדפן דורשות שרת פעיל בכתובת http://localhost:5173/ ודפדפן Microsoft Edge מותקן. הן מכסות פתיחה ישירה של עמודים, עברית וכיווניות, תצוגה בארבעה רוחבי מסך, תפריט נייד, שאלות נפוצות וחלון מידע. צילומי מסך נשמרים בתיקיית תוצאות הבדיקה.

## תוכן ופרטי קשר

- התוכן לארבעת תחומי הפעילות והגדרות הקשר מרוכזים בקובץ [src/content.ts](src/content.ts).
- מספרי הטלפון והוואטסאפ ריקים בכוונה. כפתורי הקשר אינם פעילים עד להזנת פרטים אמיתיים; האתר אינו מדמה משלוח פניות.
- מספר וואטסאפ יש להזין בפורמט בינלאומי, עם קידומת מדינה וללא סימן פלוס. לדוגמה מבנית בלבד: קידומת ישראל ולאחריה המספר ללא האפס הראשון.
- הרקע התורני מבוסס על הטקסט שסופק במהלך העבודה, לא על אימות עצמאי. המקור וההסתייגות זמינים בחלון הרקע התורני בעמוד הבית.
- התוכן והעיצוב אושרו למימוש בעברית. פרסום התוכן, ההסמכות והתפקידים עדיין דורש אישור סופי.

## תמונת ההמחשה

התמונה המקומית מציגה ספרייה ואינה צילום של הרב או תיעוד פעילותו. היא מסומנת באתר כצילום להמחשה.

- מקור: https://images.unsplash.com/photo-1507842217343-583bb7270b66
- תנאי השימוש של המקור: https://unsplash.com/license
- יש להחליפה בתצלום מתאים של הרב לאחר קבלת התמונה ואישור שימוש.
- הגופנים מותקנים מקומית דרך Fontsource; אין טעינה של גופנים או שירותי מדידה מצד שלישי בזמן הגלישה.

## לפני פרסום

יש להשלים פרטי קשר ותצלום, לאשר את הטקסט, לבדוק נגישות ודרישות פרטיות ולהגדיר את האחסון. תגית מניעת האינדוקס נשארת פעילה בינתיים.

לפריסה באחסון סטטי נדרשת הפניה פנימית של כתובות העמודים אל index.html, משום שהנתיב מוצג באמצעות הקוד בצד הדפדפן. אין לראות בבדיקות המקומיות אישור לפריסה או הצהרה על עמידה מלאה בתקן נגישות.
